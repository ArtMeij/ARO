# AVM Bicep conventions (from `avm/res/container-service/managed-cluster`)

Reference: https://github.com/Azure/bicep-registry-modules/tree/main/avm/res/container-service/managed-cluster and the AVM specs at https://azure.github.io/Azure-Verified-Modules/

## Folder layout
```
avm/res/<provider>/<resource>/
  main.bicep        # module
  main.json         # compiled (generated)
  README.md         # generated by utilities/tools/Set-AVMModule.ps1
  version.json      # { "version": "0.1" }  (major.minor; the patch is set by CI)
  CHANGELOG.md
  <child>/main.bicep  # child resource modules (AKS: agent-pool, maintenance-configuration)
  tests/e2e/<scenario>/main.test.bicep (+ dependencies.bicep)
      scenarios: defaults, waf-aligned, max, plus extras
```

## main.bicep structure
1. `metadata name` / `metadata description`
2. Parameters. Descriptions start with `Required.`, `Optional.` or `Conditional.`. Resource IDs are named `...ResourceId`. Passthrough objects are typed `resourceInput<'Type@api'>.properties.x?`.
3. Imports from `br/public:avm/utl/types/avm-common-types:<ver>`: `lockType`, `roleAssignmentType`, `managedIdentityAllType`/`managedIdentityOnlyUserAssignedType`, `diagnosticSettingFullType`, `privateEndpointSingleServiceType`, `customerManagedKeyType`.
4. Variables: `formattedUserAssignedIdentities` (array → object reduce), `identity`, `builtInRoleNames`, `formattedRoleAssignments`, `enableReferencedModulesTelemetry = false`.
5. `avmTelemetry` deployment resource: `46d3xbcp.res.<provider>-<resource>.${replace('-..--..-', '.', '-')}.${substring(uniqueString(deployment().name, location), 0, 4)}`.
6. The main resource, then child modules (pass `enableTelemetry: enableReferencedModulesTelemetry`).
7. `<res>_lock` (`Microsoft.Authorization/locks@2020-05-01`), `<res>_diagnosticSettings`, `<res>_roleAssignments` (`Microsoft.Authorization/roleAssignments@2022-04-01`, name `guid(res.id, principalId, roleDefinitionId)`).
8. Outputs: always `resourceId`, `name`, `resourceGroupName`, `location`. Nullable outputs use `string?` with `.?` access. `systemAssignedMIPrincipalId` is included when relevant.
9. `// Definitions //` section with `@export()` user-defined types, each property with a `Required.`/`Optional.` description.

## Tests
- Test files use `targetScope = 'subscription'`, create the RG `dep-${namePrefix}-<provider>.<resource>-${serviceShort}-rg`, and have `serviceShort` as a short code plus `namePrefix = '#_namePrefix_#'`.
- `dependencies.bicep` creates the prerequisites and outputs IDs.
- The module runs twice with `@batchSize(1)` over `['init', 'idem']` to prove idempotency.
- `waf-aligned` must pass the PSRule WAF checks; `max` exercises every parameter.

## Common-types version
AKS uses 0.6.1; the latest is **0.7** (we use `0.7.0`).
